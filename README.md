# Employee_Management_System

A **console-based Employee Management System developed in C** for managing employee records efficiently.

## 🚀 Features

* Admin login authentication
* Add, view, update & delete employees
* Search employees by ID
* Sort employees by ID or name
* Binary file handling for data persistence
* Salary & tax calculation
* Employee tax report generation

## 🛠️ Tech Stack

* **Language:** C
* **Concepts:** Structures, Arrays, Functions, File Handling, Searching & Sorting
* **Storage:** Binary & Text Files
* **Platform:** Command Line

## 📂 Project Structure

```text
Employee_Management_System/
│
├── EMPLOYEE_MANAGEMENT_SYSTEM_PROJECT.c/
│   └── main.c
│
├── employees.data
├── employees.txt
└── README.md
```

* `main.c` → Complete C source code
* `employees.data` → Employee records stored in binary format
* `employees.txt` → Generated employee/tax report
* `README.md` → Project documentation

## 🎯 Project Objective

This project demonstrates the practical implementation of **C programming, data management, file handling, algorithms, and problem-solving** through a real-world employee management application.
